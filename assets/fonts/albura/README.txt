Theme: https://wordpress.com/theme/bibliophile
Theme download: https://public-api.wordpress.com/rest/v1/themes/download/bibliophile.zip

These four OTF files are unmodified copies. Their embedded name-table license
records (IDs 13 and 14) specify SIL Open Font License 1.1. See OFL.txt.
The original theme README also mentions Apache 2.0; that mixed attribution is
not used here because the font binaries themselves explicitly identify OFL.

albura_normal_400.otf: regular
albura_italic_400.otf: italic
albura_normal_545.otf: semibold, mapped to CSS bold
albura_italic_541.otf: semibold italic, mapped to CSS bold italic

No font conversion, subsetting, renaming, or glyph modifications were made.
Chinese glyphs are supplied by local serif fallback fonts, not by Albura.
